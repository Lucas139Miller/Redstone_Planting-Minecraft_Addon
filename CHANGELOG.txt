NOTE:

-Minecraft has not support for redstone outside Beta version, so some features 
was made with "no propper tools for redstone". So you may take care with some 
details when using this mod:
	>Redstone signal must spend more than 10 tick (time higer than 0.5 seconds)
	>Oly redstone dust, redstone block and redstone torch can feed PLant Block
	>Avoid using too much Plant Bloks! It can lag your world - worry only if you use many of them!

-At the moment, this addon allows just planting wheat, with not supply. I intend to
work on this block to make it plant other seeds, add an interface for refuel the seeds you want
to plant, allow it to connect with hopper and maybe add new tool blocks later
